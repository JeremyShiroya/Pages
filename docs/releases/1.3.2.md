# Pages 1.3.2

This release improves device-book discovery, PDF classification, metadata search, and the reading interface.

- Restores catalog metadata, cover, and series updates while keeping PDF document classification separate from book metadata.
- Adds review and personal-document flows for PDFs, including notification follow-up and safer handling of uncertain files.
- Improves format switching, device rescans, duplicate prevention, and missing-series details.
- Adds the silver search orb to metadata and cover searches.
- Sets the new floating, compact, frosted bottom navigation as the default only for readers who have not customized their navigation.
- Adds a choice between daily compliments and a personal bio on the profile.
- Refines the book-type control, frosted metadata dialog, and cover-search progress text.
