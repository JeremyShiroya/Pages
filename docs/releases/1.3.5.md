# Pages 1.3.5

This release adds two optional on-device narrators and strengthens reading resume.

- Adds Pocket TTS Charles and Kokoro Nicole to the Android Listen narrator picker. Charles appears below Liam and Nicole below Sonia. Stars mark Liam, Charles, Ryan, Sonia, and Nicole. Each local voice downloads its model once, then works offline. Both use the existing Listen playback and speed controls.
- Saves EPUB position using a text anchor and page location, and PDF position using its page and exact scroll offset. A local recovery journal protects recent position changes when the app is closed.
- Restores EPUB reading content from the original archive when a stored extraction is missing or unreadable. Also fixes a Capacitor Preferences startup error that could incorrectly show “No readable content found.”

The local voices use different model runtimes from Edge. Their first sentence can take several seconds to prepare. Charles uses Kyutai’s published Charles preset state with the on-device LiteRT Pocket TTS port and no pitch processing. Word highlighting remains sentence-level for the local voices because these models do not provide word timestamps through this integration.

The [LiteRT Android port](https://github.com/john-rocky/LiteRT-Models) is MIT licensed.
