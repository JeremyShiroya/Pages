# Bookish 1.3.1

This release brings more control over the mobile bottom navigation and improves the way books and profile photos are handled on Android.

## New and improved

- Customize the bottom navigation in Settings → Preferences → Bottom navigation. Choose a standard or floating bar, standard or compact size, flat or frosted material, selected-tab style, filled or line icons, and adjust opacity and blur. The preview lets you try each tab without leaving settings.
- Show your profile avatar in the navigation and optionally hide tab titles. In compact mode with titles hidden, the avatar stays the same size whether Profile is selected or not. The selected background glides between tabs and fades away behind an active avatar.
- Choose a profile photo from your device, move and zoom it to crop, or continue using the built-in avatars. Your photo appears across the profile and navigation views.
- Search playlists alongside books, authors, and series. The home search hint now cycles through those categories.
- Improve light and muted theme colors, system bar contrast, button shapes, and book completion and favourite indicators.
- Fix device-imported book deletion so a failed Android file removal no longer appears to succeed. Updated installs also remove cached library entries when a later scan confirms the original device file is gone.
